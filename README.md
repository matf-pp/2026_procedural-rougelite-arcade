## Running the game

<!-- Building -->
## Building and editing

### Prerequisites

* You only need to download the LOVE2D framework, it comes with a built-in Lua compiler. We mainly used Visual Studio Code for development, with Lua and Love2D Support extensions by sumneko and Pixelbyte Studios, respectively.

### Installation

1. Download [LOVE2D](https://love2d.org/) from the official site.
2. (Optional) Add LOVE2D install directory to PATH environment variable for quick compilation from terminal
